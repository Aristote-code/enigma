## Examples

### Variants

<ComponentPreview name="link-button-variants" peekCode />

Use `variant` to set the color treatment: `gray` (default), `black`, `primary`, or `destructive`.

Set `size` to `medium` (default) or `small` to match surrounding text.

Pass `underline` to keep the underline visible at rest, and use `disabled` to render the button as non-interactive.
