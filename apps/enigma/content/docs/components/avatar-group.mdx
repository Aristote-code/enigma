## Usage

```tsx
import { Avatar, AvatarFallback, AvatarGroup, AvatarImage } from 'ui'
```

```tsx
<AvatarGroup max={4}>
  <Avatar>
    <AvatarImage src="https://github.com/mildtomato.png" alt="@mildtomato" />
    <AvatarFallback>MT</AvatarFallback>
  </Avatar>
  <Avatar>
    <AvatarFallback>SC</AvatarFallback>
  </Avatar>
</AvatarGroup>
```

Wrap any number of `Avatar` children in `AvatarGroup`. Each avatar is overlapped and given a ring so it reads cleanly against the ones behind it. Set `max` to cap how many avatars render before a `+N` indicator summarizes the remainder.
