## Usage

```tsx
import { HorizontalStepper } from 'ui'
```

```tsx
<HorizontalStepper
  steps={[{ label: 'Account' }, { label: 'Profile' }, { label: 'Done' }]}
  currentStep={1}
/>
```

Each step is an object with a `label` and an optional `description`. The `currentStep` index (zero-based) determines each step's status: steps before it render as completed, the step at the index is current, and steps after it are upcoming. Pass `onStepClick` to make the steps interactive — it receives the clicked step index.
