
```tsx

```

## Examples

### Variants

<ComponentPreview name="rating-variants" peekCode />

Use the `size` prop to render the stars at `sm`, `md` (default), or `lg`. The `value` prop accepts half values such as `3.5`, and `readOnly` makes the rating display-only. Set `max` to change the number of stars (defaults to `5`).
