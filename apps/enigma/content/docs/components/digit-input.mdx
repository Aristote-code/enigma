
### Variants

<ComponentPreview name="digit-input-variants" peekCode />

Use `gap` to control the spacing between boxes (`tight`, `default`, or `loose`), and `length` to set the number of digits. Set `isError` to apply error styling to every box, and `disabled` to make the input non-interactive.
