## Usage

```tsx
import { SegmentedControl } from 'ui'
```

```tsx
<SegmentedControl
  items={[
    { value: 'list', label: 'List' },
    { value: 'board', label: 'Board' },
  ]}
  value={value}
  onValueChange={setValue}
/>
```

Pass the options through `items`, where each item is an object with a `value` and a `label`. The control is controlled: provide the currently selected `value` and an `onValueChange` callback that receives the next value. The `label` accepts any React node, so you can render text, icons, or both.
