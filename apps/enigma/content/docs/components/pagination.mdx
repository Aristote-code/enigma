## Usage

```tsx
import { Pagination } from 'ui'
```

```tsx
<Pagination currentPage={currentPage} totalPages={10} onPageChange={setCurrentPage} />
```

The component is controlled: pass the 1-indexed `currentPage` and `totalPages`, and update your state in the `onPageChange` callback. Use `siblingCount` (default `1`) to control how many page numbers appear on each side of the current page before ellipses are shown.
