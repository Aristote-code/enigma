```

<Datepicker value={date} onChange={setDate} />
```

## Examples

### Variants

<ComponentPreview name="datepicker-variants" peekCode />

The `Datepicker` is controlled via `value` and `onChange`. Use `placeholder` to set
the empty-state label, `formatLabel` to customize how the selected date is rendered,
and `disabled` to deactivate the trigger.
